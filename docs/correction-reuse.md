# Qwenモデルの再利用と処理時間

「Qwen補正モデルを再利用する」は初期状態では無効です。Qwenを選び、有効にして設定を保存すると、次の自動補正・手動プレビューから適用します。Apple Foundation Modelsは従来どおりOS管理のモデルを使い、この設定は適用しません。比較・固定サンプル自己診断は従来どおり各試行でモデルを読み直します。

モデルは最初の補正要求で読み込みます。同じモデルパス・ファイルのサイズ／更新日時・CPU／Metalで次の補正を行う場合、子プロセスと重みを再利用します。生成用の文脈・KVキャッシュ・サンプラー・入力本文は要求ごとに作り直します。会話履歴の機能ではなく、過去の発話やOCR文脈を次のプロンプトへ追加しません。メモリの安全消去を保証する機能ではありません。

無効時と同様に本文はパイプだけで渡し、HTTPサーバー・ネットワーク接続・本文ログ・一時ファイルは作りません。新しいOS権限は不要です。保持するモデルは最大1つです。

## 解放と取り消し

- 最後の処理が終わってから5分間使わなければ、既存の状態監視で子プロセスを停止・回収します。
- 設定保存、録音の破棄、音声モデルの再読込、比較開始、アプリ終了で解放します。
- 補正処理中に新しく録音するなどの取り消しが起きると、その処理のプロセスも停止・回収します。古い応答を次の要求や直接入力へ転用しません。
- 成功後に新しく録音を始める場合は、待機中のモデルを維持して再利用します。
- 棄却・異常終了・応答上限超過・タイムアウトもセッションを終了します。入力の自動再送や別エンジンへの切替はせず、既存の原文保持・直接入力の規則に従います。

子プロセスの停止・回収によりモデルのOS資源を解放します。GPUの解放量や実機での空きメモリ表示の変化まではCIで測定していません。

## 時間の見方と診断

「処理時間」には次を表示します。成功した補正だけに内訳があり、未計測の項目は0秒と区別します。

| 項目 | 範囲 |
|---|---|
| 音声認識 | ワーカー内の音声前処理・Whisper推論。録音時間やキュー待ちは含まない |
| 補正全体 | アプリ側で観測した起動・パイプ・生成・検証の待ち時間。再利用時の待機時間は含まない |
| 初期化・読込 | Qwenのバックエンド初期化と重み読込。再利用した要求では0 |
| 文脈準備・入力処理 | その要求専用の生成用文脈作成・トークン化・prefill |
| 生成・検証 | 文章生成と原文保持チェック |

Qwenの内訳はヘルパー内の計測で、補正全体とは計測境界が異なります。Appleの内訳は公開されないため未計測とし、補正全体には追加の原文保持チェックも含めます。成功時のQwenでも子の終了・OSキャッシュ・温度などに影響され、再利用により必ず一定の割合で速くなるとは限りません。

「処理時間・診断情報をコピー（本文なし）」で、音声認識時間・補正の時間内訳・重み再利用の有無・有効設定・既存の固定エラー／Apple利用可否をコピーできます。音声・認識本文・補正本文・画面情報・モデルパスは含みません。通常はファイルへ保存しません。

## CIと最後の実機確認

通常CIでプロセスの再利用・取り消し・期限切れ・設定変更相当の解放・モデル置換・応答上限・回収を模擬ヘルパーで検証します。明示実行の実モデル評価では、ネットワーク禁止のCPU推論で、毎回読込とA→B→Aの再利用を比較します。数値と検証結果だけをArtifactに残します。

実機では同じ音声を再認識し、再利用の有効・無効で出力と待ち時間を比較してください。Metalの性能・メモリ使用量とAppleの実推論は実機確認事項です。証明書・公証は引き続き先送りします。
