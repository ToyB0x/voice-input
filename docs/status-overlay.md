# 録音ステータスの小型表示

「録音ステータスを小型表示する」は初期状態で無効です。設定を保存してから新しい録音を開始すると、メインディスプレイの作業領域の下部中央に表示します。録音・認識・自動補正・入力完了・原文利用・入力見送りを確認できます。

- 録音中は録音時間と入力レベルを表示します。レベルは既存の録音PCMから得た値で、別のマイクを開きません。
- 認識・補正中は、その段階を観測してからの経過時間も表示します。時間表示は約50ms間隔の状態観測に基づく目安です。
- 完了・入力見送り・失敗・取り消しは4秒間表示してから隠れます。録音を破棄した場合や、モデル読み込みへ移った場合は隠れます。設定で無効にすると隠れ、有効化しても同じ録音の途中から再表示しません。
- 固定サンプル比較など、録音に伴わない手動作業では新しく表示しません。結果の本文や詳しい失敗理由は設定画面で確認してください。

オーバーレイはキーボードとマウスの操作を受け取りません。表示のためにアプリをアクティブ化したりキーウィンドウにしたりせず、入力先のフォーカスを維持します。録音・停止・取り消しは既存のショートカットや設定画面を使います。ウィンドウは固定位置で、ドラッグ移動やボタン操作はありません。

初版はメインディスプレイに表示します。他のディスプレイで入力している場合も同じ位置です。Spacesやフルスクリーンアプリ上での見え方はmacOSのウィンドウ管理にも依存します。

## データと権限

別のWebViewへ渡すのは、表示の有無・固定の状態／メッセージ・録音時間・段階の経過時間・レベルだけです。音声・認識本文・補正本文・画面情報・入力先の識別子・モデルパスは渡しません。表示用ウィンドウには、この読み取り専用APIだけを許可し、録音・コピー・設定変更・ウィンドウ操作のコマンド権限を与えません。

新しいOS権限や非公開macOS APIは使いません。既存の録音・直接入力・画面情報取得の権限は、それぞれの機能で従来どおり扱います。

## CIと実機確認

通常CIでは、状態遷移・終了表示の期限・無効化・破棄・再表示防止・本文を含まないJSON、ブラウザー側の表示と通信の重複防止、ウィンドウ設定とコマンド権限を検証します。

さらに、専用のテストアプリを前面にして、製品と共通の公開AppKit表示処理でオーバーレイを2回表示・非表示するネイティブテストを実行します。キーウィンドウになれないこと、マウス操作を無視すること、フローティング表示、前面アプリの維持を確認します。WebView本文の描画成功や実際のクリック送信を検証したものではありません。画像・音声・AX権限を付けずに実行します。

GHA27 PreviewのWebView空画面問題と、このネイティブ検証は区別します。実機では設定を有効にして別アプリで録音し、文字とレベルが見えること、入力欄のフォーカスが変わらないこと、完了後に隠れることを確認してください。ディスプレイ倍率・複数画面・Spaces／フルスクリーンの見え方も最後の実機確認事項です。
