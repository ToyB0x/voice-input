# 録音不要の補正自己診断

Apple Foundation Modelsが実際に日本語を生成できるか、音声認識や画面情報の取得と切り離して確認します。アプリ内の固定文5件だけを使い、録音済み音声・認識本文・基準文・AX/OCRの情報はモデルへ渡しません。マイク・アクセシビリティ・画面収録の許可は不要です。AppleのオンデバイスモデルとローカルQwenを使い、クラウド推論へ切り替えません。

## 操作

1. 「実機で一括比較」を開き、「Appleモデルの固定サンプル診断」を押します。音声モデルの準備や録音は不要です。Apple Intelligenceに対応した実機では、OS側でApple Intelligenceとモデルを準備しておきます。
2. Qwenも比較する場合は、先にQwenの補正モデルを準備し、通常の最終補正欄にモデルパス・CPU / Metalを設定して保存します。その後「AppleとQwenの固定サンプル比較」を押します。録音比較欄のCPU / Metal選択ではなく、保存済みのQwen設定を使います。
3. 下の共通一覧で、固定原文・補正候補・採否・失敗理由・処理時間を確認します。Appleのみ5件、Qwenも使うと同じ固定文を各エンジンへ渡して10件を直列実行します。各子プロセスを終了・回収してから次へ進みます。
4. 「比較を中止」で実行中の子を停止・回収します。「比較結果を破棄」で診断と結果を消去します。アプリ終了時も同じ中止処理を使います。
5. 「比較レポートJSONをコピー」で結果を共有できます。初期状態では本文を除外します。固定原文と候補も共有したい場合だけ、本文を含めるチェックを選びます。

開始すると前の比較結果を置き換え、常駐Whisperモデルを解放します。通常の録音や認識の実行中は開始できません。録音・文字起こし結果そのものは上書きしません。通常の音声入力に戻る前に音声モデルを読み込み直してください。

## 固定サンプル第1版

| ID | 確認したい内容 |
|---|---|
| `numbers` | 午後3時、会議室B、10人という情報の保持 |
| `negation` | 本番へ適用しないという否定の保持 |
| `self-repair` | 金曜日ではなく木曜日への言い直し |
| `filler-punctuation` | フィラー除去、句読点、処理順序の保持 |
| `list-format` | 持ち物の抜けや追加のない整形 |

入力はアプリ内の公開サンプルで、版はレポートの`sampleSetVersion: 1`に記録します。`mode: fixed-correction`と各行の`sampleId`で録音比較と区別します。音声認識は実行せず、音声時間・AX/OCR文字数は0、ASR時間とCERは未計測です。生成結果の意味・自然さ・整形は原文と比較して判断してください。

## 成否の読み方

`done`は全条件の処理が終わった意味で、全件成功や高品質を意味しません。Appleの利用可否確認の`available`も生成成功とは別です。

- `accepted`: モデルが生成した候補が共通の原文保持チェックを通過。意味の同一性や最適な整形を保証するものではありません。
- `rejected`: 候補は生成されたものの、数字や否定などの保持チェックで棄却。最終出力には固定原文を残します。
- `unavailable`: Apple利用不可またはQwen未準備。生成せず固定原文を残します。
- `error`: ヘルパーや生成・検証が失敗。成功扱いにせず固定原文を残します。

Appleの利用可否・OS版・確認時間も共通画面とレポートに表示します。[Appleモデルの診断表](apple-foundation-models.md#診断と切り分け)を参照してください。各条件は補正最大150秒とApple候補の検証最大10秒で、全件の上限は長くなる可能性があります。処理時間には毎回のモデル読込とIPCを含み、事前の利用可否確認やWhisperモデル解放は含めません。OSキャッシュ・温度・実行順によって変わります。

## CIと実機確認

通常CIでは実際の補正経路に模擬ヘルパーを接続し、固定文だけの入力、Apple／Qwenの直列実行、前の子の回収、利用不可・生成失敗・棄却時の原文保持、実行中の中止、本文を除外したレポートを検証します。GUI・権限操作ツールはコンパイルし、追加コマンドのTauri権限定義もアプリビルドで検証します。

Appleモデルの利用可否自体はGHAで実APIを確認します。GHAの`deviceNotEligible`や模擬生成を実推論成功とは扱いません。既知のPreview空画面問題でGUI操作に到達しない範囲は未確認のまま残します。実機では最初にAppleのみを実行し、生成した候補が表示されるか、日本語の意味と整形が妥当かを確認してください。OSのApple Intelligence設定が必要な場合だけ、利用者が設定します。マイクや画面取得の許可を先に付ける必要はありません。
