# アプリでのモデル準備とプリセット

「モデルの準備・選択」で組み合わせまたは個別モデルを選びます。起動・選択だけでは通信しません。

1. モデル名・容量・ライセンス・実行時メモリの目安を確認し、「ダウンロードして準備」を押します。既に正しいファイルがある場合は検証だけで再利用します。取得先は固定した公式Hugging Faceモデルです。通信するのはモデル取得だけで、音声・画面情報・認識結果を送信しません。
2. 容量とSHA-256の検証が成功したら、「検証済みモデルを設定欄へ反映」を押します。手入力していたパスは、ここで反映するまで変わりません。
3. 実行方式を選んで「設定を保存」し、音声モデルの「モデルを読み込む」を押します。保存した音声モデルは次回起動時にも読み込みます。補正モデルはプレビュー操作時だけ読み込みます。

保存済みモデルには「保存済みモデルを検証」を使えます。この操作はネットワークを使わず、同じ容量でもSHA-256が異なるファイルを拒否します。検証に失敗した場合は、明示的なダウンロード操作で再取得してください。手動準備したカスタムモデルの絶対パスも従来の入力欄から利用できます。

| プリセット | 音声認識 | 最終補正 |
|---|---|---|
| 軽量 | Whisper base | 無効 |
| 認識重視 | Whisper medium | 無効 |
| 大きい音声モデル | Whisper large-v3-turbo | 無効 |
| 整形比較 | Whisper medium | Qwen3 4B、手動プレビュー・コピー |

プリセットは準備するモデルを選ぶ機能です。実行方式、画面情報の取得元・利用先、直接入力、OS権限は変更しません。「整形比較」の場合も、文脈を使うなら既存の取得元とWhisper／補正への利用先を利用者が明示的に選んで保存してください。補正結果の自動入力は行いません。

モデルは `~/Library/Application Support/dev.toyb0x.voiceinput/models/` に保存します。容量は配布ファイルの値で、実行時メモリやダウンロード時に必要な空き容量とは異なります。Qwen3の表示するRSSは過去のLinux CPU評価の目安で、音声モデル・アプリ・GPUなどの分は別途必要です。実機の速度や最大メモリを保証する値ではありません。

「準備を取り消す」またはアプリ終了で取得プロセスを終了・回収し、未検証の部分ファイルを削除します。準備する複数モデルの一部が完了していた場合、検証済みモデルは再利用のため残します。途中結果を設定へ自動反映しません。強制終了やOSクラッシュで残った `download-*.part` は、アプリを終了してから上記フォルダで削除できます。中断箇所からのダウンロード再開は行いません。

アプリのフロントエンドは外部のHTTP接続を許可せず、Rust側で固定IDだけを受け付けます。取得にはmacOS同梱の `/usr/bin/curl` を使い、ユーザーのcurl設定を無効にしてHTTPSだけを利用します。取得リビジョン・容量・SHA-256は `crates/local-models/catalog.json` をアプリとPythonの準備・評価スクリプトで共有します。モデル重みはアプリやArtifactへ同梱しません。

## CIと評価

Macの実UIで、プリセットが画面取得設定を変えないこと、実際のモデル取得とキャンセル、部分ファイル削除、baseの検証・設定反映・読み込み・再起動時の復元を確認し、スクリーンショットと結果JSONを保存します。取得処理の単体テストでは、破損・容量不一致を公開せず、既存の正しいファイルを保持することを確認します。

`Model preset evaluation` はmedium／large-v3-turboそれぞれの公開音声をCPUで認識し、その同じ出力をQwen3 4Bへ渡す4条件を比較します。推論は通信禁止で実行し、各音声モデル自身の補正前CER・補正後CER・棄却・時間・RSS・全文・差分を残します。全条件と両組み合わせが揃った結果だけを `model-preset-summary` に集計します。固定音声・正解語彙を含むヒントによる感度試験で、一般の自然発話や実OCRのランキングではありません。句読点・書式はCERと別の指標で確認します。

Apple Foundation Modelsの利用可能な実機での評価、実機Metalの性能確認、モデルの常駐化は後続です。証明書・公証は引き続き先送りとし、インストール・起動の手順は[利用ガイド](user-guide.md)を参照してください。
