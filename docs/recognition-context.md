# 入力欄を使ったローカル認識補助（実験的）

設定の「入力欄の周辺テキストで認識を補助する」を選び、設定を保存すると、次の録音から有効です。初期状態および旧設定ファイルからの移行時は無効です。「直接入力」とは独立した設定なので、結果を自動挿入せずに認識補助だけ使えます。

別アプリの入力欄を選び、録音ショートカットを押して離してください。Voice Input内で録音を開始した場合、自分の設定画面は読み取りません。Accessibilityの許可は直接入力と共通で、明示的な「アクセシビリティの許可を確認・設定」ボタンから設定します。未許可でもマイクによる音声認識を継続します。利用者のMacでの許可操作はmacOS自身の同意画面で行います。

## 読み取る範囲と用途

録音開始時に、前面アプリのフォーカスされた編集可能なAXTextAreaまたはAXTextFieldだけを対象にします。パスワード欄、読み取り専用、非テキスト要素、安全性を確認できない欄は除外します。親要素・画面全体・他ウィンドウは探索しません。

選択範囲の開始位置から前後最大256 UTF-16コード単位、合計512単位以内を、AXStringForRangeで要求します。大きな選択でも取得量は増えません。文字数や範囲取得に非対応の場合、全文のAXValue取得に切り替えずヒントなしで続行します。範囲の境界が絵文字などの途中に当たり取得できない場合も同様です。取得後に入力先と選択位置を再確認し、変化があれば使いません。

制御文字（NULを含む）を除去し、UTF-8で最大768バイトに制限したテキストを、ローカルWhisperのinitial_promptとして渡します。辞書の強制置換やLLMへの命令として扱う処理はありません。ただしWhisperが画面上の語句に引っ張られ、発話にない言葉を出す可能性があります。内容を確認し、誤認識が増える場合は設定を無効にしてください。無音はヒントの有無によらず空の結果とします。

## データの扱い

音声と認識補助はこのMac内だけで処理します。取得したテキストをファイル、ログ、設定、クリップボード、フロントエンドIPCに出力せず、クラウドへ送信しません。画面撮影・OCR・Apple Foundation Modelsはこの段階では使いません。画面収録権限も不要です。

テキストはRust側の一時メモリに置き、最初の認識に一度だけ渡します。新しい録音、破棄、設定の無効化、録音開始の失敗、認識前処理の失敗やジョブの破棄、アプリ終了で保留中のテキストを削除します。再有効化で古いヒントは復活しません。録音だけを行いモデルをまだ読み込んでいない場合は、認識または破棄まで保持します。認識開始後のネイティブ処理は安全に強制終了できないため、その処理中のコピーは終了時に解放されます。メモリの暗号化・ゼロ埋めを保証する機能ではありません。

再試行はヒントなしで行い、画面を再取得しません。モデルごと・録音ごとに新しいデコーダー状態を作り、以前のヒントを次の録音へ引き継ぎません。UIには取得の成否と文字数だけを表示し、テキスト本体は表示しません。

直接入力も有効にした場合、従来どおり挿入直前に入力先・選択位置・内容を照合します。認識ヒントは、直接入力による誤挿入防止を緩めません。なお直接入力を有効にすると、別途その既存の内容照合のために全文の一時的なハッシュ計算を行います（[直接入力](direct-insertion.md)）。

## CIの確認と認識評価

Mac CIでは実際のOS許可・拒否、実マイク経由の音声認識、取得範囲、機能無効時・保護された欄・読み取り専用欄の除外、非対応欄での継続、破棄、設定無効化、再試行、再起動を検証します。CI専用のネイティブ入力欄でAccessibilityの全文・範囲読み取り回数を記録し、認識補助だけ有効にしたときに全文取得0回、範囲要求512単位以内を確認します。製品に権限や取得結果を偽装するテスト用機能はありません。Artifactは合成テキスト・公開音声のみです。

Model evaluationの`model-evaluation-base`と`model-evaluation-small` Artifact内の`context/`に、同じ公開音声・モデルを用いたヒントなし／関連語句／無関係な語句の比較、全認識結果、CER、無音の誤出力、無関係なカナリア語句の一致を保存します。評価プロセスのネットワークは禁止します。

関連ヒントには正解文から選んだ語句を意図的に含めています。これは制御された感度試験であり、実利用での平均的な精度向上を証明するものではありません。無関係語句の一致も完全な誤混入検出器ではなく、正規化後の完全一致に限られます。モデルや録音内容により改善と悪化の両方があり得るため、実験的な設定として提供します。
