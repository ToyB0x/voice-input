# 録音からローカル文字起こしまで

## 利用手順

1. [モデル準備手順](local-transcription.md)で多言語版の `ggml-base.bin` を用意する。
   準備用のコマンドだけがネットワークを使う。アプリはダウンロード・外部推論を行わない。
2. アプリにモデルの**絶対パス**を入力し、GPU（Metal）または CPU を選んで「モデルを読み込む」。
   モデルは次の録音でも再利用する。「設定を保存」でモデルのパス・実行方式・ショートカットを保存し、
   次回起動時に設定を復元してモデルを読み込む。音声と認識結果は保存しない。
   [常駐・ショートカットと個人利用の手順](user-guide.md) も参照。
3. 「録音を開始」。未確認の場合のみ macOS の実際のマイク許可ダイアログが出る。
4. 「停止」または最大60秒で、モデル読み込み済みなら自動で日本語文字起こしする。
   未読み込みなら録音だけを保持し、後でモデルを読み込んで「文字起こし・再試行」を押せる。
5. 結果を確認し、必要なら「結果をコピー」。クリップボードへの書き込みはこの操作時だけ行う。

モデル未配置・破損・英語専用版はエラーを表示する。別のパスや CPU を指定して再読み込みできる。
GPU の初期化状況はエンジンの診断ログを参照。表示の「GPU / Metalを選択」は要求した方式であり、
GPU が使えない場合も外部サービスへ切り替えない。CI では実際の Metal 初期化も検証する。

## 音声と結果の扱い

録音はデバイスのレートでモノラル PCM として Rust のメモリに保持する。
認識時に rubato の FFT フィルターで帯域制限しながら16 kHzへ変換し、変換の遅延を除去する。
1秒未満の音声は無音で1秒まで補い、最大60秒の上限は維持する。
入力レベル・時間・状態・認識結果のみ IPC に含め、音声を WebView や外部へ送らない。
モデル読み込み・変換・認識は専用ワーカーで実行し、録音のコールバックでは行わない。

「破棄」、新しい録音、アプリ終了でアプリ内の録音と認識結果を消す。
認識中にも破棄でき、古い世代の結果は画面へ戻さない。
ただしネイティブ推論そのものは強制停止せず、ワーカーが処理を終えるまで一時 PCM が残る。
その間は「実行中の処理の終了を待っています」と表示し、新しい録音やモデル変更を待たせる。
モデルのロード中に破棄した場合も、ロード終了後にそのモデルを解放する。
処理中のモデル・音声の同時操作を直列化し、無制限のジョブ待ち行列を作らない。

コピー済みの文字列はシステムクリップボードに残る。アプリの破棄操作ではクリップボードを上書きしない。
録音・結果の自動ファイル保存は行わない。結果のコピーは利用者の明示操作として扱う。

## CI

既存の実際のマイク許可・拒否、録音・停止・破棄に加え、製品アプリを通常起動して次を確認する。

- UIから未配置モデルを指定し、エラーを確認。その後、ローカルモデルを指定して読み込む。
- 実際のマイク許可ダイアログを操作する。
- 公開された CC0 の日本語音声を `afplay` で BlackHole 仮想マイクへ流す。
- 録音停止から自動文字起こしを行い、画面の認識結果に「船」「旅」が含まれることを確認する。
- コピーボタンを押し、実際のシステムクリップボードが画面の結果と一致することを確認する。
- モデルを再ロードせず再認識し、認識中に破棄。終了後に古い結果が戻らず、モデルが保持されることを確認する。

製品に CI 専用の音声注入・権限バイパスは設けない。アプリの追加OS権限はなく、
CIドライバー側のアクセシビリティ権限で通常の画面操作を行う。
エンジン単体のネットワーク拒否下での推論検証も継続する。

Artifacts の `macos-window-smoke-1/transcription/` に各状態の画面、公開音声の認識結果、
クリップボード一致と破棄の判定を保存する（末尾は実行回数、保存14日）。音声・モデルは含めない。
音声の出典・利用条件は [fixtureの説明](../crates/local-transcription/tests/fixtures/README.md) を参照。

CIは仮想マイク・公開音声・macOS 14のApple Silicon環境での検証。
自然発話の精度、物理マイク固有の挙動、他のOS・デバイスでの性能は後続で評価する。
今回、人による権限確認を前提にした未完了の検証は設けない。

このCIはデータ経路の検証であり、全文一致による精度評価ではない。仮想マイク経由では
base が「月日」を「月皮」と認識した例もあるため、複数の主要語と実際のコピー結果で疎通を確認する。
固定した読み上げ音声のモデル比較は [実測結果](model-evaluation.md) を参照。自然発話の精度評価は後続の作業とする。
