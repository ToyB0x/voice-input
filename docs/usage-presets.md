# 実測を基にしたプリセットの準備と適用

「モデル」タブの「かんたん設定」で使い方を選ぶ。現時点の実機結果では一般的な「最良」は確定していない。原文の意図を変えにくい初期候補と、比較用の構成を区別する。

|モード|必要モデル|画面文脈|最終補正|
|---|---|---|---|
|原文重視（推奨）|Whisper large-v3-turbo、約1.62GB|無効|自動補正なし|
|文字の文脈をヒントにする（実験）|同上|入力欄のAX＋OCRをWhisperへ|自動補正なし|
|整形をプレビューする（比較用）|turbo＋Qwen3 4B Q4_K_M、合計約4.12GB|無効|認識後に手動でプレビュー|

すべてMetalを選ぶ。実行メモリはファイル容量より大きくなる。画像分類・VLMはこれらの通常入力プリセットには含まれない。AFMは反復抑制が改善した一方、文体の変更や誤認識の回復に課題があり、今回の推奨には含めていない。

## 操作

1. プリセットを選び、説明・根拠・必要容量を確認する。選択だけでは設定や権限を変更しない。
2. 「必要なモデルを準備」を押す。取得済みなら容量・SHA-256を検証し、不足・不整合があれば固定した公式配布元から取得する。中止や失敗では設定を保存しない。
3. 検証完了後、「設定を保存して読み込む」を押す。パス転記や別の保存操作は不要。現在の設定欄を基にプリセットを適用し、音声モデルを読み込む。
4. 「準備と設定が完了」と表示されたら「音声入力」へ戻る。初回録音では必要に応じてmacOSのマイク確認が表示される。

録音・比較・補正結果が残っているときは、保存適用の前にコピーして破棄するよう案内する。アプリは結果を自動で消さない。モデル準備だけは先にできる。モデルの読み込みに失敗した場合、設定は保存済みと明記し、エラーを確認して個別のモデル欄から再読み込みできる。

画面文脈の実験モードでは、保存時にAXとOCR取得を有効にする。アクセシビリティ・画面収録の許可は「設定」タブから明示的に確認する。許可がなくてもプリセットは保存でき、取得不可は状態表示に残る。通常OCRの撮影範囲はフォーカス中の編集欄で、画面全体や別の画像を解析する設定ではない。

## 変わる設定と保持する設定

音声モデルをturbo／Metalへ、自動補正とQwenモデル再利用をオフへ変更。追加指示は空にし、最終補正向けの文脈利用をオフにする。文字ヒントのモードだけAX／OCR取得をオンにする。Qwenプレビューでは補正パス・方式もQwen3 4B／Metalへ切り替える。

ショートカット・直接入力・小型表示などの欄はそのまま保存する。未保存の変更も現在の設定欄から保存する。モデル準備の選択を変えた場合や別の準備を行った場合は再検証が必要で、古い完了結果では適用しない。個別設定を手動保存すると、保存モード表示は「個別設定」になる。

## 選定の根拠と限界

[実機の音声込み結果](../evaluation/preset-evidence/v0.0.4/provenance.json)は、turbo／Metal＋AFM新テキスト方式・追加指示なしの2反復。同じ合成音声を使う小規模な試験であり、幅広い精度ベンチマークではない。補正52実行中44採用・8棄却で反復はなかったが、キャンディ側の期待語を回復できず、語尾や表現の変更が残った。原文を保持し、手動で整形を確認する構成を初期候補にしている。

文字ヒントは表記を変える一方、逆の文脈で誤誘導も観測している。Qwenの標準指示では過去の固定例で句読点・フィラー除去を確認したが、更新後プロンプトとturboの組み合わせが最良とは未検証。これらは明示選択する比較用である。

CIはモデル取得・検証・中止・古い世代の拒否、設定と既存項目の保持、ブラウザでの準備→保存→読み込みの導線を確認する。大きいモデルを毎回ダウンロードして精度を評価する検証ではない。
