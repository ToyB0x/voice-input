# 認識後の自動補正と最終結果の入力

「認識後に自動補正する」は初期状態で無効です。有効にして設定を保存すると、その後に開始する文字起こしで、保存済みApple／Qwen設定による補正を自動実行します。録音停止時の認識と、録音済み音声の再認識が対象です。音声と取得文脈をクラウドへ送信しません。

## 準備と使い方

1. まず[固定サンプルの自己診断](correction-selftest.md)で、選択モデルの生成・意味保持・待ち時間を確認してください。
2. 補正エンジンとQwenのモデルパス／CPU・Metalを選び、「認識後に自動補正する」を有効にして設定を保存します。AppleではOS側のモデル準備が必要です。
3. 録音・停止すると、Whisper原文を残したまま補正します。「最終結果」に採用した補正結果を表示し、「最終結果をコピー」でコピーできます。失敗・ガードによる棄却・モデル未準備・タイムアウトではWhisper原文を最終結果にします。他のモデルへ自動では切り替えません。
4. 直接入力も有効な場合は、録音開始時に記録した入力先へ、補正完了後の最終結果を一度だけ渡します。原文を先に入力してから置き換える方式ではありません。完了時に入力先・選択範囲・内容が異なる場合、権限がない場合、パスワード欄などでは入力を見送ります。クリップボードへのフォールバックや自動再試行はしません。

補正中のメニューバーは「処理中」です。新しい録音や「録音を破棄」は引き続き利用できます。新しい録音・破棄・モデルの再読み込み・再認識・設定保存・アプリ終了は古い補正を取り消します。取り消しは補正失敗の原文入力とは区別し、遅れた成功・失敗のどちらも自動入力しません。設定保存で取り消した場合、原文は最終結果に保持して手動コピーできます。

自動補正を無効にすると、従来どおりWhisper原文が最終結果です。直接入力の有効・無効は自動補正と独立しています。直接入力を無効にしたまま、自動補正・コピーだけを使えます。古い設定ファイルに新しいフラグがなくても、無効として読み込みます。

手動の「最終補正をプレビュー」は引き続き自動入力せず、認識時に確定した最終結果も上書きしません。手動候補を使う場合は「補正結果をコピー」を選んでください。再認識で作成した最終結果も、すでに消費した録音開始時の入力先へ再度自動入力しません。画面情報の利用は既存の取得元・利用先フラグに従い、その録音に対応する初回補正だけで使います。

## 確認範囲

通常CIでは、補正成功・棄却時の原文保持・遅延・取り消し・設定変更・終了を模擬ヘルパーで検証します。最終結果の確定と入力は同じ録音世代・未消費状態で一度だけ実行し、本文をログに出力しません。既存のAX入力先の再検証を維持し、権限バイパスは追加しません。実OSでの許可拒否と補正失敗の組み合わせは独立Preview GUIテストにも追加します。

GHA27 Previewの空画面問題でGUI操作に到達できない範囲は未確認です。対応実機では最初に直接入力を無効にして自動補正を確認し、その後テスト用の別アプリ入力欄で一度だけ入力されること、入力先を変えると入力を見送ることを確認してください。Appleの実推論・日本語品質・実機のOS権限許可は、この最後の確認に含みます。
