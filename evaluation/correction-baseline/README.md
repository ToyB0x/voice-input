# 補正の固定ベースライン

`qwen3-8b.json`は[PR #12のLinux CPU実測](https://github.com/ToyB0x/voice-input/actions/runs/40092438784)から保存した、固定合成テキスト9件の入力・参考文脈・正解・生成結果です。個人の録音や画面情報は含みません。ソースコミット、モデルの公式リビジョン・SHA-256、当時のランタイムソースとケースファイルのハッシュを記録しています。

評価時にはモデルの固定情報と入力・文脈・正解の一致を検証します。過去のラベルは使わず、現在の同じ制約で旧出力と新出力を再採点します。追加ケースは変更前後の比較から除外し、別に評価します。Artifactの`baseline.diff`で文章の差を確認できます。

これは同じ9入力での品質比較です。異なるランナーの速度比較、自然発話での性能、一般的な意味の一致を保証するものではありません。棄却・実行失敗による原文保持も、生成成功とは区別します。

## 4Bと保持判定

`qwen3-4b-preservation.json`は[PR #14の4B評価](https://github.com/ToyB0x/voice-input/actions/runs/40123819092)の固定20件とsmall経由32入力、[プリセット評価](https://github.com/ToyB0x/voice-input/actions/runs/40123819093)のmedium / large-v3-turbo各32入力を保存したものです。各実測のソース・モデル・ランタイム・コーパスの識別情報を含みます。旧20件の入力を変更すると比較を拒否します。新規8件は別に集計し、音声経由は認識文字列・文脈・正解の完全一致した組だけで比較し、除外件数を示します。原文保持を含む最終結果の語句チェックと、生成成功の事実／書式チェックを分けます。

`guard-preservation.json`はマージ後の`aec0b58a2a5f3625d36c680470ab83b9d8a4b59f`にある保持判定を、固定32ペアで実行した観測値です。入力と旧ソースのSHA-256を記録しています。旧実装の問題候補の誤受理9件、正常候補の誤棄却0件を新実装と比較します。モデル推論の結果や実利用の誤り率ではありません。すべて公開・合成テキストで、個人の画面や録音は含みません。
