# 手元のMacでのAFM＋Vision実測

測定元は利用者がチャットで共有したVoice Input v0.0.2、macOS 27.0.1、aarch64の1実行。`reportId: device-18e2364919fedba0-1`。CIでAFMを実行した結果ではない。CIはこの固定データの整合性・資料生成・レイアウトだけを検証する。

## データの来歴

- `diagnostic.json`：利用者が最初に添付した本文なしJSONをバイト列のまま保存。時刻、採否、自動判定、取得状態、ハッシュを含む。
- `results.json`：同じreportIdの本文付き共有から、原文・取得文脈・短い候補と最終結果・補助試験を転記した**解析用スナップショット**。元の全文エクスポートではない。
- 標準指示で発生した長い異常候補8件（主試験6＋かな対照2）は、先頭を`candidateExcerpt`、`candidateTruncated:true`で保存。`candidate:null`のままにし、反復の回数や省略部分を推定して再構成しない。短い出力・最終結果は全文を保持する。
- `provenance.json`はこのスナップショットと元の診断添付のSHA-256を保持。全文共有JSON全体のSHA-256を示すものではない。
- `presentationSlides`は本実測に対する解釈。汎用生成器へ今回だけの結論を埋め込まず、このデータと一緒に版管理する。

## 観測と解釈

主試験は、かな原文「あめがすごいですね」、2シーン、7取得条件、補正なし／AFM標準／AFM追加指示、各1回の42行。うちAX未許可と文字なし画像OCRの空文字による未実行12行。42件の独立した発話ではない。Whisper・音声認識・音声ヒントは実行していない。

追加指示は「発話の意味を保ち、参考文脈に合う一般的な漢字表記へ整えてください。参考文脈にある内容を本文へ追加せず、数字・人名・否定の意味を保持してください。」。

|追加指示の文脈|台風側の最終文|キャンディ側の最終文|
|---|---|---|
|なし|雨がすごいですね|雨がすごいですね|
|直接テキスト|雨が強いです|飴がすごいですね|
|文字OCR|雨が強いです|飴がすごいですね|
|Vision分類|雨がすごいですね|飴がすごいですね|
|逆のテキスト|飴がすごいですね|雨が強いです|

画像から得たラベルによってキャンディ側は「雨→飴」に変化した。台風側は文脈なしですでに「雨」なので、単独で画像の効果を示す例にはしない。画像自体をAFMへ直接渡すVLMではない。画面全体や他アプリの撮影でもない。

標準指示の主試験は4採用（かなのまま）、6棄却。棄却候補は文脈の転載と「支援者: Apple」「質問には回答しません」等の反復。すべて原文へ戻った。原因は未特定であり、悪意ある入力の存在やAFM一般の性能をこの実行だけで断定しない。

追加指示の主試験10件は全採用、期待語7・逆語3。ただし逆文脈の負の対照も含み、全体を「精度70%」とは呼ばない。「雨が強いです」への語調の変化が採用されたため、期待語・ガード採用・意味保持を別々に評価する。

固定の意味保持試験は標準／追加指示で6例ずつ。数字、否定の適用範囲、曜日の対比、人名は最終文に保持。フィラー「えー」は除去、「まず」と人名は保持。追加指示の数字例は「3→三、10→十」の候補を`guard-numbers`が棄却して原文へ戻した。値の誤りと表記差を混同しない。持ち物の文は箇条書きにならなかった。

文字OCRは台風21739 ms、キャンディ311 ms。画像分類は36／29 ms、文字なし画像OCRは32／32 msで成功・空文字。最初のOCRの遅さが初期化によるものかは未検証。AFM主試験の補正中央値は標準8631.5 ms、追加指示778.5 msだが、前者の長い異常出力と実行順が交絡するため、単純な速度改善率にしない。

## 次に切り分けること

1. 現在の結果を保存した上で2反復にし、順序反転後も標準指示の異常生成と追加指示の出し分けが再現するか。
2. AXを許可し、取得結果を直接テキスト／OCRと比較する。
3. 「CIと同じ同梱音声」、次に実話者の録音で、Whisperヒント／最終補正／両方を比較する。かな補正の結果を音声精度の改善として流用しない。
4. 標準指示のプロンプト・JSON入力・構造化出力を別PRで切り分ける。棄却ガードを緩めて異常候補を通さない。

```sh
mise exec -- python3 scripts/context-slides.py --report evaluation/context-evidence/device-afm-v0.0.2/results.json --output /tmp/device-afm-slides

```
